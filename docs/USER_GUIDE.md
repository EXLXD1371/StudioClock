# 演播时钟 · Studio Clock 1.0

适用于 Windows 10 / 11，64 位。解压后双击 StudioClock.exe 即可运行，无需安装 Node.js、Rust 或额外的服务器。

软件使用 Windows 的 Microsoft Edge WebView2 Runtime 显示界面。通常系统已自带；如果电脑缺少它，请从微软官网下载并安装 Evergreen Runtime（x64）：
https://developer.microsoft.com/microsoft-edge/webview2/

## 开始使用

1. 点击“开播设置”或开播时间卡片右上角箭头，选择开播日期与时间，精确到分钟。
2. 保持“到点自动开始”开启。到点之前主计时为零；到点后自动计时，距离开播停在零。
3. 主计时可手动开始、暂停、继续和重置；独立计时有自己的一组开始、暂停和重置按钮。
4. 标题栏图钉可将窗口置顶，全屏按钮或 F11 可进入全屏。拖动标题栏移动窗口，拖动窗口边缘调整尺寸。

绿色：当前时间与主计时。红色：开播时间、独立计时时长、距离开播。所有数字使用随软件内置的等宽字体。

## 快捷键

- Space：主计时开始 / 暂停（焦点位于按钮或输入框时，保留控件本身的按键行为）。
- T：独立计时开始 / 暂停。
- F11：进入 / 退出全屏。
- Esc：关闭设置；没有设置对话框时退出全屏。
- Ctrl+,：打开开播设置。

## 计时规则

- 首次打开默认计划为下一次 19:00。可手动选择今天、明天或其他日期。过去的时间不能保存为新计划。
- 开播计划是一次性的，不会每天重复。下一场请重新设置日期和时间。
- 关闭自动开始只会禁用到点启动，不会暂停已经运行的主计时。
- 在开播前手动开始主计时，到点时会继续原计时，不会归零；若开播前暂停且自动开始仍开启，到点会继续累计。
- 到点后暂停或重置主计时，不会被自动开关再次启动；请手动开始或设置新计划。
- 若自动开始原本关闭，过了开播时间后首次开启，会补计从计划开播到当前的时长。
- 保存新的开播计划会重置主计时，独立计时保持不变。
- 小时数可超过 24，计时不按天归零。

## 保存与离线运行

设置和计时状态自动保存在当前 Windows 账户本地。关闭后重新打开，暂停的计时仍暂停；运行中的计时会计入关闭期间的时长。开播期间关闭程序不会执行后台任务，重新打开时才按计划时间补计。

程序不会自动修改系统时间。时钟与计时均基于本机时间戳，窗口最小化或暂时休眠后会补计；修改系统时间或系统大幅校时也会影响计时结果。

字体、图标和界面已内置，正常运行无需网络。窗口置顶和全屏状态不跨启动保留。

数据位于当前用户本地应用数据目录中的 com.studioclock.desktop（WebView2 本地存储）。EXE 可放在任意文件夹，移动 EXE 不会迁移其他 Windows 账户的数据。
